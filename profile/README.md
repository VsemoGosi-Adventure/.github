# 🧭 Авантюра — Геолокационный сервис спонтанных встреч

> **Команда:** «ВсёмоГуси»  
> **Дисциплина:** Объектно-ориентированное программирование  
> **Формат:** Клиент-серверное приложение с микросервисной архитектурой  
> **Стек:** Go, PostgreSQL 16 + PostGIS, Redpanda, Traefik, WebSockets, React Native (TypeScript), Docker

---

## 📌 1. Концепция и решаемая проблема

**«Авантюра»** — это геолокационный сервис для поиска компании по интересам «здесь и сейчас» (спорт, пробежка, настольные игры, кофе, прогулка).

### В чём проблема классических решений?
1. **Долгий сбор:** В соцсетях и пабликах организация встречи растянута во времени.
2. **Пассивность пользователей:** Обычный пользователь не хочет сам придумывать мероприятие, искать площадку и модерировать сбор — он хочет получить готовое предложение рядом с собой в удобный момент.

### Как это решает «Авантюра»?
* 🛠 **Кураторская модель (Роль Crawler):** Обычные пользователи не создают события в случайных местах. Базу проверенных городских локаций (парки, корты, антикафе, коворкинги) и расписание сборов формируют верифицированные организаторы/менеджеры (**Crawler-ы**).
* 🔔 **Проактивные Push-уведомления (Работа в фоне):** Приложение само напоминает о себе и присылает уведомления, когда рядом с пользователем намечается или начинается событие по его интересам.
* ⚡ **Радар «Пинг рядом»:** Участники уже идущей встречи могут нажать кнопку «Пингануть рядом» — система найдёт пользователей поблизости с подходящими интересами и отправит им приглашение присоединиться прямо сейчас.
* 🔒 **Приватность геолокации:** Пользователи не отображаются друг у друга на карте как живые точки. Точные координаты пользователя используются только внутри бэкенда для расчёта радиуса (`PostGIS`), а детали закрытых встреч доступны только участникам.
