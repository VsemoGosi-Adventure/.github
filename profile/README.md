# 🧭 Авантюра — Геолокационный сервис спонтанных встреч

> **Команда:** «ВсёмоГуси»  
> **Дисциплина:** Объектно-ориентированное программирование  
> **Формат:** Клиент-серверное приложение с микросервисной архитектурой  
> **Стек:** Go, PostgreSQL 16 + PostGIS, Redpanda, Traefik, WebSockets, React Native (TypeScript), Docker

---

## 📌 1. Концепция и решаемая задача

**«Авантюра»** — это платформа для поиска и организации спонтанных мероприятий по интересам («здесь и сейчас»). Сервис решает проблему высокого порога входа при создании событий, избавляя пользователей от рутины ручного поиска площадок, составления расписания и привлечения аудитории.

### Ключевые принципы работы:
* **Курируемый контент (Crawler):** Актуальное расписание мероприятий и база проверенных городских локаций формируются автоматически с помощью изолированных фоновых модулей сбора данных из внешних агрегаторов.
* **Асинхронная архитектура:** Разделение контуров сбора данных и основной бизнес-логики через отказоустойчивый брокер сообщений гарантирует стабильность работы приложения даже при высоких нагрузках или ограничениях со стороны внешних источников.
* **Пространственный анализ (GIS):** Сопоставление интересов и геолокации пользователей происходит на базе географических индексов, что позволяет оперативно находить интересные активности в ближайшем радиусе.

---

## 🏗 2. Архитектура системы

Система построена на базе независимых сервисов, каждый из которых выполняет строго определенную роль:
1. **Модуль сбора данных (Crawler):** Автономный микросервис, периодически опрашивающий внешние платформы, нормализующий данные и передающий их в систему.
2. **Брокер сообщений:** Обеспечивает буферизацию, гарантированную доставку и асинхронную обработку потока событий.
3. **Основной бэкенд:** Отвечает за доменную логику, работу с пользователями, REST API и пространственные расчеты.
4. **Клиентская часть:** Мобильное приложение для взаимодействия с картой, уведомлениями и управлением участием во встречах.
